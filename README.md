## Como executar

### Pré-requisitos

Antes de rodar o projeto, você precisa ter instalado:

- Python 3
- As seguintes bibliotecas Python:
  - `pandas` — leitura e manipulação do dataset
  - `colorama` — cores no terminal
  - `matplotlib` — geração dos gráficos

### Executando no VS Code

1. Abra a pasta do projeto inteira no VS Code (`File > Open Folder`), não só a pasta `src`.
2. Certifique-se de ter a extensão **Python** instalada no VS Code.
3. Abra o arquivo `src/main.py`.
4. Clique no botão de play (▶) no canto superior direito, ou pressione `Ctrl + F5`.
